## 📲 갤럭시 / 아이폰에 앱(PWA)으로 다운로드하는 방법
1. 위 링크를 **Chrome** 또는 **삼성 인터넷**으로 접속합니다.
2. 첫 화면의 **`[📲 스마트폰 앱(PWA) 다운로드 · 홈 화면 설치]`** 버튼(또는 우측 상단 **`[📲 앱설치]`**)을 터치하면 즉시 앱 설치 창이 열립니다.
   * **인앱 브라우저(카카오톡 등)에서 열었을 경우:** 안내 창의 **`[🌐 Chrome 브라우저로 열어서 바로 설치]`** 버튼을 누르면 바로 크롬이 열리며 설치할 수 있습니다.
   * **아이폰 / 아이패드 (Safari):** 하단 중앙 **`[공유 ↑]`** → **`[홈 화면에 추가]`** 선택

## 🔥 v3.0 HD 리마스터 주요 특징
* **프리렌더링 3D PBR 스프라이트 & 심리스 항공 지형:** 산호초 해군 기지, 강철 협곡 공창 요새, 적색 폭풍 야간 함대 등 라운드마다 변화하는 고해상도 전장과 실제 기체 실루엣 고도 그림자, 12프레임 볼륨 화염 폭발 연출
* **5단계 기체 외형 & 무장 진화 (`LV.1` → `MAX`):** `[P]` 아이템 획득 시 3D 확장 기관포 포드·골드 에이스 장갑·자율 사격 윙맨 드론 2기 합류
* **3종의 초대형 3페이즈 보스 (`IRON VALKYRIE` · `YAMATO-X` · `GIGA LEVIATHAN`):**
  * 좌·우 주포 포탑이 살아있는 동안 중앙 코어 장갑이 피해를 경감하므로 **양날개 주포 포탑을 먼저 파괴**하는 정통 부위 파괴 공략
  * 체력 `65%` 2페이즈 나선 탄막 개방 → 체력 `30%` 3페이즈 발악 교차 탄막 패턴 및 라운드별 난이도·체력 점진 상승
