# 🚀 STAR GALAGA — 모바일 레트로 스페이스 슈팅 PWA

설치나 회원가입 없이 스마트폰·PC 브라우저에서 즉시 실행되고, **홈 화면에 추가하여 네이티브 앱처럼 오프라인에서도 즐길 수 있는 정통 갤러그(Galaga) 스타일 레트로 아케이드 슈팅 게임**입니다.

## 🎮 바로 플레이 & 스마트폰 앱(PWA) 설치 주소
👉 **[https://kairen7683-cyber.github.io/star-galaga-pwa/](https://kairen7683-cyber.github.io/star-galaga-pwa/)**

## 📱 스마트폰에 앱(PWA)으로 설치하는 방법
* **안드로이드 (Chrome / 삼성 인터넷):**
  1. 위 링크 접속 후 첫 화면의 **`[📲 스마트폰에 앱(PWA)으로 설치]`** 버튼 터치 (또는 브라우저 메뉴 `⋮` → `앱 설치 / 홈 화면에 추가`)
* **아이폰 / 아이패드 (Safari):**
  1. Safari로 위 링크 접속
  2. 하단 중앙 **`[공유 ↑]`** 아이콘 터치 → **`[홈 화면에 추가]`** 선택
  3. 바탕화면에 생성된 **스타갤러그** 아이콘을 실행하면 주소창 없는 전체화면 앱으로 작동하며, 비행기 모드(오프라인)에서도 플레이 가능합니다.

## ⚡ 주요 기능 및 기믹
* **정통 갤러그 편대 비행 & 급강하 공격:** 베지어 곡선 궤적을 따라 진입해 숨 쉬듯 움직이는 편대와 급강하(Dive) 공격
* **보스 트랙터 빔 & 호위 편대:** 2번 타격해야 파괴되는 보스 기체의 트랙터 빔 및 호위기 동반 강습
* **챌린징 스테이지 (보너스 스테이지):** 매 3스테이지마다 곡예비행 편대 등장 (24기 전원 격추 시 `+10,000점` 퍼펙트 보너스)
* **파워업 캡슐:**
  * `D` (**Dual Fighter**): 기체 2대가 나란히 합체해 2연장 화력 발사 (피격 시 1기만 손실되어 생존력 2배)
  * `R` (**Rapid Laser**): 초고속 연사 모드
  * `S` (**Shield**): 적 탄환 및 충돌 1회 완벽 방어 에너지 실드
  * `B` (**Hyper-Nova Bomb**): 화면 전체 탄막 제거 및 적 전체 광역 타격 폭탄 추가
* **100% 자체 합성 레트로 사운드:** 외부 음원 파일 없이 Web Audio API로 실시간 합성되는 8비트 아케이드 효과음
