# ✈️ STRIKERS 1945 : SKY ACE — 고화질 모바일 종스크롤 슈팅 PWA

설치나 회원가입 없이 스마트폰·PC 브라우저에서 즉시 실행되고, **홈 화면에 추가하여 네이티브 앱처럼 오프라인에서도 즐길 수 있는 정통 1945 스타일 고품질 아케이드 슈팅 게임**입니다.
삼성 **갤럭시 A 시리즈** 등 중보급형 스마트폰에서도 발열·버벅임 없이 **고정 60 FPS**로 구동되도록 오프스크린 메탈릭 스프라이트 베이킹(Offscreen Atlas Pre-baking) 엔진을 적용했습니다.

## 📱 스마트폰에 앱(PWA)으로 설치하는 방법
* **안드로이드 (Chrome / 삼성 인터넷):**
  1. 위 링크 접속 후 첫 화면의 **`[📲 스마트폰 홈 화면에 앱(PWA) 설치]`** 버튼 터치 (또는 브라우저 메뉴 `⋮` → `앱 설치 / 홈 화면에 추가`)
* **아이폰 / 아이패드 (Safari):**
  1. Safari로 위 링크 접속
  2. 하단 중앙 **`[공유 ↑]`** 아이콘 터치 → **`[홈 화면에 추가]`** 선택
  3. 바탕화면에 생성된 **1945에이스** 아이콘을 실행하면 주소창 없는 전체화면 앱으로 작동하며, 비행기 모드(오프라인)에서도 플레이 가능합니다.

## ⚡ 주요 시스템 및 기체/무기 진화

### 1. 개성 뚜렷한 3종의 주력 전투기 선택
* **P-38 라이트닝 (`HOMING`)**: 와이드 트윈 발칸 + 적기를 끝까지 추적하는 **호밍 유도 미사일**
* **XF-5F 스카이레이 (`LASER`)**: 집중 연사 발칸 + 직선상의 적 편대를 꿰뚫는 **관통 플라즈마 레이저**
* **J7W 신덴 (`NAPALM`)**: 초고화력 중기관포 + 착탄 시 주변까지 초토화하는 **네이팜 광역 폭발 로켓**

### 2. 아이템 획득에 따른 5단계 기체 외형 & 탄환 업그레이드 (`LV.1` → `MAX`)
* **`LV.1`**: 기본 동체 + 2연장 기관포
* **`LV.2`**: 강화 장갑 도색 + 3방향 발칸 + 보조 부무장(미사일/레이저/로켓) 개방
* **`LV.3`**: **확장 윙팁 및 강화 엔진 외형 진화** + **자율 사격 윙맨 드론 1기 합류** + 4연장 발칸
* **`LV.4`**: 2연발 부무장 강화 + **좌우 양날개 자율 윙맨 드론 2기 편대 완성**
* **`LV.5 (MAX OVERDRIVE)`**: **황금 에이스 도장 & 트윈 애프터버너 최종 기체 진화** + 5방향 플라즈마 풀화력 + 풀파워 상태에서 `[P]` 추가 획득 시 `+2,000점` MAX 보너스

### 3. 아케이드 아이템 & 전술 시스템
* **`[P]` 파워업 아이템**: 화면 벽을 튕기며 떠다니는 파워업 캡슐 (기체 외형 및 무기 단계 상승)
* **`[B]` 편대 폭격 아이템**: B-29 전략폭격기 편대를 호출하여 화면 전체 적 탄막 소거 및 융단폭격 지원사격
* **`[S]` 에너지 실드**: 기체 주변에 방어막을 전개하여 적 탄환/충돌 1회 완벽 방어
* **`★` 회전 골드 메달**: 격추된 중형기·함선·지상 포대에서 드롭되며 가까이 다가가면 자석처럼 흡수 (`+200 ~ +1,000점` 연속 보너스)
* **다중 부위 파괴 거대 보스전**: 스테이지마다 등장하는 거대 공중요새/전함의 좌우 주포 포탑을 먼저 파괴해 탄막을 약화시킨 뒤 코어를 격파하는 정통 1945 보스 공략
